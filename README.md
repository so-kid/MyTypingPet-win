# MyTypingPet for Windows

キーを打つたびに、キャラクターが左右の手を交互に上げてぴょこっと跳ねる Windows 用デスクトップペットです。

![既定のキャラクター (待機 / 左手 / 右手)](docs/preview.png)

[swoonqx/TypingPet](https://github.com/swoonqx/TypingPet) から着想を得た、独立したプロジェクトです (本家とは関係ありません)。macOS 版は [MyTypingPet for Mac](https://github.com/so-kid/MyTypingPet-mac) をご覧ください。

## 主な機能

- どのアプリで入力しても反応する (システム全体のキー入力を検知)
- DualSense (PS5) / DualShock 4 (PS4) を USB でつなぐと、パッドのボタンにも反応する
- 待機・左手・右手の画像を好きなものに差し替え (PNG / JPG / GIF / BMP)
- **パターン** — 特定の入力で別の画像を表示 (最大 10 個)
  - 修飾キー + 特定のキー (例: `Ctrl + S`, `F5`)
  - 修飾キー + 任意のキー (例: `Ctrl` を押しながら何かのキー)
  - 修飾キー単独 (例: `Shift` を押して離す)
  - マウスクリック (左 / 右 / 中 / サイドボタン、修飾キーとの組み合わせ可)
  - パッドのボタン (× ○ □ △、十字キー、L1〜R3、Create/Share、Options、PS、タッチパッド、ミュート)
- **プリセット** — 画像とパターンの一式に名前を付けて保存し、切り替えられる (最大 10 個)
- サイズ 4 段階、常に最前面、位置ロック (クリック透過)、PC 起動時の自動実行
- タスクトレイに常駐。タスクバーと Alt+Tab には出ない

## 動作環境

- Windows 10 / 11
- [.NET 8 デスクトップランタイム](https://dotnet.microsoft.com/download/dotnet/8.0) (ビルドする場合は .NET 8 SDK)

## ダウンロード

[Releases](https://github.com/so-kid/MyTypingPet-win/releases/latest) から `MyTypingPet.exe` をダウンロードして実行します。インストールは不要です。

- .NET 8 デスクトップランタイムが入っていない場合は、初回起動時にインストールを案内する画面が出ます。
- 初回起動時に SmartScreen の「Windows によって PC が保護されました」が出ることがあります。「詳細情報」→「実行」で起動できます。

## ソースからビルドする

```powershell
dotnet run
```

exe 1 本にまとめる場合:

```powershell
dotnet publish -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true -o publish
```

`publish\MyTypingPet.exe` ができます。

## 使い方

起動すると画面右下にペットが現れます。左ドラッグで好きな場所へ移動できます。

ペットまたはタスクトレイのアイコンを**右クリック**するとメニューが開きます。

| メニュー | 内容 |
|---|---|
| 画像を変更 | 待機 / 左手 / 右手の画像を選ぶ。「既定の絵に戻す」でネコに戻る |
| パターン | パターンの追加・キー変更・画像変更・削除 |
| パターンの表示時間 | 1 / 1.5 / 2 / 3 秒、または次の入力まで |
| プリセット | 画像とパターンの一式を保存・適用・上書き・名前変更・削除 |
| サイズ | 小 / 中 / 大 / 特大 |
| 常に最前面 | 他のウィンドウより手前に表示 |
| 位置ロック | クリックがペットを通り抜ける。解除はトレイアイコンから |
| 位置リセット | 画面右下に戻す |
| PC起動時に実行 | ログイン時に自動で起動 |
| 終了 | アプリを終了 |

### 画像

- 推奨は **800 × 500 px の透過 PNG** です。
- 待機・左手・右手を同じキャンバスサイズ・同じ位置基準で作ると、切り替わりが自然になります。
- 表示サイズと縦横比は待機画像を基準に決まります。
- GIF はアニメーションせず、1 コマ目だけが表示されます。

### パターン

「パターン」→「パターンを追加...」でダイアログが開きます。登録したい入力を行い、続けて表示する画像を選びます。

| 登録したいもの | ダイアログでの操作 |
|---|---|
| `Ctrl + S` など | そのまま押す |
| `Ctrl + 任意のキー` | 「組み合わせるキーは何でもOK」にチェックして、`Ctrl` を押して離す |
| `Shift` 単独 | 押して、他のキーを押さずに離す |
| `Ctrl + 右クリック` など | `Ctrl` を押しながら枠の中を右クリック |
| パッドの `△` など | ダイアログを開いたままパッドのボタンを押す |

- 1 つの入力に登録できるパターンは 1 つです。
- 特定のキーのパターンは「任意のキー」より優先されます。
- 修飾キーは完全一致で判定します (`Ctrl + 任意のキー` は `Ctrl + Shift + A` では発動しない)。
- マウスクリックは、パターンに登録したものだけに反応します。
- パッドのボタンは DualSense と DualShock 4 で共通です (`パッド ×` はどちらの × でも発動)。ミュートは DualSense だけにあります。
- パターンの画像は「パターンの表示時間」で選んだ時間 (既定 1.5 秒) 表示されたあと、待機の画像に戻ります。表示中に別のキーを押すと、すぐに通常の動きに戻ります。

### プリセット

「プリセット」→「現在の設定を保存...」で、待機・左手・右手の画像とパターンの一式を名前付きで保存できます (最大 10 個、名前は 16 文字まで)。サイズや位置などの表示設定は含みません。

保存したプリセットは、メニューから「適用」「今の設定で上書き」「名前を変更」「削除」ができます。

- 画像はプリセットごとに別フォルダへコピーして保存されるので、あとで画像を差し替えてもプリセットの中身は変わりません。
- 適用すると、今の画像とパターンはプリセットの内容に置き換わります。残しておきたい場合は先に保存してください。

## データの保存場所

設定と画像はすべて `%AppData%\MyTypingPet\` に保存されます。

| パス | 内容 |
|---|---|
| `settings.json` | 位置・サイズ・各種設定・パターン |
| `images\` | 選んだ画像のコピー (元のファイルを移動・削除しても影響なし) |
| `images\presets\` | プリセットごとの画像のコピー |
| `error.log` | 問題が起きたときの記録 |

アンインストールするには、「PC起動時に実行」をオフにしてから、exe とこのフォルダを削除してください。

## プライバシー

- キー入力は Windows の Raw Input で「押されたこと」を受け取るだけで、入力を横取りしたり書き換えたりはしません。
- 押されたキー・ボタンの種類は、オートリピートの判定とパターンとの照合にだけ使い、**保存も送信もしません**。
- ネットワーク通信は一切行いません。

## ゲームと一緒に使うときの注意

MyTypingPet はゲームのプロセスに触れず (メモリの読み書き・DLL 注入・入力の送信をしない)、入力を読むだけです。ただし、透明で最前面に表示される窓は外部オーバーレイ型のチートツールと見た目が似ているため、アンチチートの厳しいゲームでは問題になる可能性があります。

- ペットはゲーム画面に重ねず、別のモニターなどに置くことをおすすめします。
- 対戦ゲームなどでは、アプリを終了するか、「常に最前面」と「位置ロック」をオフにしてください。
- 外部ツールの利用については各ゲームの規約に従い、自己責任でお使いください。

## 既知の制約

- 管理者権限で動いているアプリ (一部のゲームなど) が前面にあるときは、キーボードとマウスの入力を検知できません。パッドの入力は検知できます。
- 独占フルスクリーンのゲームの上には表示されないことがあります (ボーダーレスウィンドウ推奨)。
- ペンやタッチの入力はクリックとして扱いません。
- ゲームパッドは DualSense と DualShock 4 (初期型・後期型) の USB 接続に対応しています。Bluetooth 接続、DualShock 4 のワイヤレスアダプター、スティック操作、DualSense Edge などには対応していません。
- 対応パッドを複数つないだときは、最初に見つかった 1 台だけを読みます。
- 十字キーの斜めは、2 方向の同時押しとして扱います (例: ↗ = 十字↑ + 十字→)。

## ソース構成

| ファイル | 役割 |
|---|---|
| `App.xaml.cs` | 起動処理、トレイアイコン、メニュー、パターン管理、自動起動 |
| `PetWindow.xaml(.cs)` | 透明なペットウィンドウ、跳ねるアニメーション、パターン照合 |
| `RawInput.cs` | Raw Input によるキーボード・マウスの検知 |
| `GamepadReader.cs` | USB 接続のパッドを HID デバイスとして直接読む (抜き差しにも対応) |
| `Gamepad.cs` | 対応機種の一覧と、USB 入力レポートからボタンを読む処理 |
| `KeyTrigger.cs` | パターンの発動条件 (修飾キー + キー / 任意 / 単独 / クリック / パッド) |
| `TriggerDialog.xaml(.cs)` | 入力を実際に行ってパターンを登録するダイアログ |
| `DefaultArt.cs` | 既定のネコの絵をコードで描画 |
| `Preset.cs` | プリセットの保存・適用 (画像のコピーを含む) |
| `ImageFiles.cs` | AppData にコピーした画像の置き場所と、安全な削除 |
| `NameDialog.xaml(.cs)` | プリセット名の入力ダイアログ |
| `Settings.cs` | 設定の読み書き |
